# Hybrid PC Monitoring System - Flutter MVP

This zip contains the separated `lib/` source code and `pubspec.yaml` for the Hybrid Computer Laboratory Access, Hardware Monitoring, and Fault Detection System.

## Setup

1. Copy the `lib/` folder into your Flutter project.
2. Copy the dependencies from `pubspec.yaml` into your existing project's `pubspec.yaml`.
3. Run:

```bash
flutter pub get
firebase login
flutterfire configure --project=no-d42ca
flutter run -d windows
```

`lib/firebase_options.dart` is intentionally not included because it should be generated by FlutterFire CLI for your Firebase project.

## Firestore test rules

For development only:

```js
rules_version = '2';

service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if true;
    }
  }
}
```

## Note

If the app shows `PC BROKEN` because your laptop has no printer, headset, or webcam, open:

`lib/services/windows_hardware_service.dart`

and comment these lines:

```dart
if (!webcamOk) issues.add('Webcam Not Found');
if (!printerOk) issues.add('Printer Not Found');
if (!headsetOk) issues.add('Headset Not Found');
```
